# Multimodal test image snapshots

These images are local snapshots of the fixed Lorem Picsum inputs referenced by
`tests/configs/image_text_model_configs.json`. Keeping the exact pixels local avoids
network failures without invalidating the committed VLM golden tokens.

- `picsum-237-536x354.jpg`: [Lorem Picsum ID 237](https://picsum.photos/id/237/info), photo by Andre Spieker.
- `picsum-238-536x354.jpg`: [Lorem Picsum ID 238](https://picsum.photos/id/238/info), photo by Anders Jilden.
