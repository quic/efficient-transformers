# QEFF Nightly Jenkins Freestyle Job Configuration

This file is a cleaned, copy-ready reference for the QEFF nightly Jenkins freestyle job.
It replaces the raw Jenkins UI paste with the required parameters, build steps, archive
rules, and email settings for the nightly pipeline under `tests/nightly_pipeline/`.

## Job

- Name: `QEFF-Nightly`
- Type: Jenkins freestyle project
- Source checkout: handled by the main shell step
- Workspace artifact directory: `Nightly_Pipeline/${BUILD_TAG}`
- Persistent nightly cache: `${NIGHTLY_DIR}/${BUILD_TAG}`

## Parameters

### Source Selection

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `AGENT_LABEL` | Node | Jenkins configured default | Jenkins agent label/node selector. |
| `BRANCH_NAME` | String | empty | Branch to run. If empty and `PR_NUMBER` is empty, `main` is used. |
| `PR_NUMBER` | String | empty | Pull request number to test. Takes precedence over `BRANCH_NAME`. |

### Model Family Toggles

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `RUN_CAUSAL_LM` | Boolean | true | Run causal LM export/generate stages. |
| `RUN_IMAGE_TEXT` | Boolean | true | Run image-text-to-text export/generate stages. |
| `RUN_EMBEDDING` | Boolean | true | Run embedding export/generate stages. |
| `RUN_AUDIO` | Boolean | true | Run audio model export/generate stages. |
| `RUN_AUDIO_EMBEDDING` | Boolean | true | Run audio embedding export/generate stages. |
| `RUN_SEQUENCE` | Boolean | true | Run sequence model export/generate stages. |
| `RUN_VALIDATION` | Boolean | true | Run nightly result validation. |
| `RUN_OTHER_TESTS` | Boolean | true | Run additional QAIC multimodal tests. |
| `RUN_FINETUNE` | Boolean | true | Run finetune tests. |

### Model Skip Lists

Each skip list is a comma-separated list of exact Hugging Face model IDs.

| Name | Applies To |
| --- | --- |
| `SKIP_CAUSAL_LM_MODELS` | Causal LM models |
| `SKIP_IMAGE_TEXT_MODELS` | Image-text-to-text models |
| `SKIP_EMBEDDING_MODELS` | Embedding models |
| `SKIP_AUDIO_MODELS` | Audio models |
| `SKIP_AUDIO_EMBEDDING_MODELS` | Audio embedding models |
| `SKIP_SEQUENCE_MODELS` | Sequence models |

### Nightly Runtime Controls

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `NIGHTLY_PIPELINE_PREVIOUS_ARTIFACTS_DIR` | String | empty | Previous artifact directory used for validation comparisons. Relative paths resolve under `${DOCKER_NIGHTLY_DIR}`. |
| `NIGHTLY_XDIST_WORKERS` | String | `1` | Worker count for export/compile pytest stages. |
| `NIGHTLY_MODEL_BATCH_SIZE` | String | `1` | Number of models per export/generate batch. Generation clears `QEFF_HOME` after each batch. |

## Required Environment

These variables must be available to the job from Jenkins/global environment or credentials binding.

| Name | Description |
| --- | --- |
| `DOCKER_LATEST` | Docker image repository/tag prefix used with `:master_latest`. |
| `DOCKER_HF_PATH` | Hugging Face cache mount path inside Docker. |
| `HF_TOKEN` | Hugging Face token. |
| `HF_PATH` | Hugging Face cache path on host. |
| `DOCKER_NIGHTLY_DIR` | Nightly artifact root path inside Docker. |
| `NIGHTLY_DIR` | Nightly artifact root path on host. |

## Build Step 1: Main Nightly Pipeline Shell

Paste this script into Jenkins **Execute shell** with the shebang as the very first
characters in the command box. There must be no blank line or space before it.
The Jenkins console should show the script running with `bash`; if it shows
`/bin/sh -xe ...`, Jenkins is ignoring the shebang and `set -o pipefail`, arrays,
and `[[ ... ]]` will fail. In that case, configure the job/node shell executable
as `/bin/bash` or re-paste the command with the shebang on line 1.

```bash
#!/usr/bin/env bash
set -uo pipefail
 
FAILED=0
OLDER_MODEL_WARNINGS=0
CHILD_PIDS=()
BUILD_START_EPOCH="$(date +%s)"
BUILD_END_EPOCH=""
BUILD_RESULT=""
BUILD_NAME="${BUILD_TAG:-qeff_build_${BUILD_NUMBER:-manual}}"
NIGHTLY_ARTIFACTS_DIR=""
 
. ~/.bashrc
 
############################################
# Helpers
############################################
 
stage() {
  echo
  echo "=================================================="
  echo "STAGE: $1"
  echo "=================================================="
}
 
mark_failed() {
  echo "FAILED: $1"
  FAILED=1
}
 
mark_warning() {
  echo "WARNING: $1"
  OLDER_MODEL_WARNINGS=1
}
 
print_host_resources() {
  echo "Host resources:"
  free -h || true
  df -h || true
  nproc || true
  sudo docker system df || true
}
 
############################################
# Docker exec (non-blocking + tracked)
############################################
 
_docker_exec () {
  sudo docker exec \
    -e SKIP_CAUSAL_LM_MODELS="${SKIP_CAUSAL_LM_MODELS:-}" \
    -e SKIP_IMAGE_TEXT_MODELS="${SKIP_IMAGE_TEXT_MODELS:-}" \
    -e SKIP_EMBEDDING_MODELS="${SKIP_EMBEDDING_MODELS:-}" \
    -e SKIP_AUDIO_MODELS="${SKIP_AUDIO_MODELS:-}" \
    -e SKIP_AUDIO_EMBEDDING_MODELS="${SKIP_AUDIO_EMBEDDING_MODELS:-}" \
    -e SKIP_SEQUENCE_MODELS="${SKIP_SEQUENCE_MODELS:-}" \
    -e NIGHTLY_PIPELINE_PREVIOUS_ARTIFACTS_DIR="${NIGHTLY_PIPELINE_PREVIOUS_ARTIFACTS_DIR:-}" \
    -e BUILD_START_EPOCH="${BUILD_START_EPOCH:-}" \
    -e BUILD_END_EPOCH="${BUILD_END_EPOCH:-}" \
    -e BUILD_RESULT="${BUILD_RESULT:-}" \
    -e BUILD_NAME="${BUILD_NAME:-}" \
    -e BUILD_TAG="${BUILD_TAG:-}" \
    -e BUILD_NUMBER="${BUILD_NUMBER:-}" \
    -e BUILD_URL="${BUILD_URL:-}" \
    -e JOB_NAME="${JOB_NAME:-}" \
    -e NODE_NAME="${NODE_NAME:-}" \
    -e BRANCH_NAME="${BRANCH_NAME:-}" \
    -e PR_NUMBER="${PR_NUMBER:-}" \
    -e GIT_COMMIT="${GIT_COMMIT:-}" \
    -e GIT_URL="${GIT_URL:-}" \
    -e DOCKER_LATEST="${DOCKER_LATEST:-}" \
    -e NIGHTLY_MODEL_BATCH_INDEX="${NIGHTLY_MODEL_BATCH_INDEX:-}" \
    -e NIGHTLY_MODEL_BATCH_SIZE="${NIGHTLY_MODEL_BATCH_SIZE:-}" \
    "${BUILD_NAME}" bash -lc "$*" &
 
  pid=$!
  CHILD_PIDS+=("$pid")
 
  wait "$pid"
  return $?
}
 
_pytest_with_xdist() {
  local pytest_file="$1"
  echo "pytest ${pytest_file} -n ${NIGHTLY_XDIST_WORKERS}"
}

count_models_for_age() {
  local model_key="$1"
  local model_age="$2"

  NIGHTLY_MODEL_AGE="$model_age" python3 - <<PY
import json
from pathlib import Path

config = json.loads(Path("tests/nightly_pipeline/configs/validated_models.json").read_text())
models = config.get("${model_key}", [])
newer_models = set(config.get("model_age_groups", {}).get("newer_models", {}).get("${model_key}", []))

if "${model_age}" == "newer":
    selected_models = [model_name for model_name in models if model_name in newer_models]
else:
    selected_models = [model_name for model_name in models if model_name not in newer_models]

print(len(selected_models))
PY
}

ceil_div() {
  local numerator="$1"
  local denominator="$2"
  echo $(( (numerator + denominator - 1) / denominator ))
}
 
############################################
# Stage wrappers (do not exit on failure)
############################################
 
run_export_stage() {
  local stage_name="$1"
  local pytest_cmd="$2"
  local model_age="${3:-}"
  local tolerate_failure="${4:-false}"
  local batch_index="${5:-}"
  local batch_size="${6:-}"
 
  stage "$stage_name"
  print_host_resources
 
  if ! _docker_exec "
    set -e
    export NIGHTLY_MODEL_AGE=${model_age}
    export NIGHTLY_MODEL_BATCH_INDEX=${batch_index}
    export NIGHTLY_MODEL_BATCH_SIZE=${batch_size}
    export NIGHTLY_PIPELINE_ARTIFACTS_DIR=${NIGHTLY_ARTIFACTS_DIR}
    mkdir -p \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR\" /qeff_models
    export QEFF_HOME=/qeff_models
    cd /efficient-transformers
    source preflight_qeff/bin/activate
    $pytest_cmd
  "; then
    if [ "$tolerate_failure" = "true" ]; then
      mark_warning "$stage_name"
    else
      mark_failed "$stage_name"
    fi
  else
    echo "SUCCESS: $stage_name"
  fi
}
 
run_generate_stage() {
  local stage_name="$1"
  local pytest_cmd="$2"
  local model_age="${3:-}"
  local tolerate_failure="${4:-false}"
  local batch_index="${5:-}"
  local batch_size="${6:-}"
 
  stage "$stage_name"
  print_host_resources
 
  if ! _docker_exec "
    set +e
    export NIGHTLY_MODEL_AGE=${model_age}
    export NIGHTLY_MODEL_BATCH_INDEX=${batch_index}
    export NIGHTLY_MODEL_BATCH_SIZE=${batch_size}
    export NIGHTLY_PIPELINE_ARTIFACTS_DIR=${NIGHTLY_ARTIFACTS_DIR}
    mkdir -p \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR\" /qeff_models
    export QEFF_HOME=/qeff_models
    cd /efficient-transformers
    source preflight_qeff/bin/activate
    $pytest_cmd
    status=\$?
 
    echo 'Cleaning QEFF_HOME'
    [ \"\$QEFF_HOME\" = \"/qeff_models\" ] && rm -rf /qeff_models/*
    unset QEFF_HOME
    exit \$status
  "; then
    if [ "$tolerate_failure" = "true" ]; then
      mark_warning "$stage_name"
    else
      mark_failed "$stage_name"
    fi
  else
    echo "SUCCESS: $stage_name"
  fi
}
 
run_validate_stage() {
  local stage_name="$1"
  local pytest_cmd="$2"
 
  stage "$stage_name"
  print_host_resources
 
  if ! _docker_exec "
    set -e
    export NIGHTLY_PIPELINE_ARTIFACTS_DIR=${NIGHTLY_ARTIFACTS_DIR}
    mkdir -p \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR\" /qeff_models
    export QEFF_HOME=/qeff_models
 
    cd /efficient-transformers
    source preflight_qeff/bin/activate
    $pytest_cmd
 
    echo 'Cleaning QEFF_HOME'
    [ \"\$QEFF_HOME\" = \"/qeff_models\" ] && rm -rf /qeff_models/*
    unset QEFF_HOME
  "; then
    mark_failed "$stage_name"
  else
    echo "SUCCESS: $stage_name"
  fi
}
 
run_model_family_stages() {
  local run_var="$1"
  local model_key="$2"
  local export_stage_name="$3"
  local export_pytest_file="$4"
  local generate_stage_name="$5"
  local generate_pytest_cmd="$6"
 
  if ! should_run "$run_var"; then
    return 0
  fi
 
  local batch_size="${NIGHTLY_MODEL_BATCH_SIZE:-1}"
  if ! [[ "$batch_size" =~ ^[1-9][0-9]*$ ]]; then
    echo "Invalid NIGHTLY_MODEL_BATCH_SIZE=${batch_size}; defaulting to 1"
    batch_size=1
  fi

  run_model_family_age_batches "$model_key" "$export_stage_name" "$export_pytest_file" "$generate_stage_name" "$generate_pytest_cmd" "older" "true" "$batch_size"
  run_model_family_age_batches "$model_key" "$export_stage_name" "$export_pytest_file" "$generate_stage_name" "$generate_pytest_cmd" "newer" "false" "$batch_size"
}

run_model_family_age_batches() {
  local model_key="$1"
  local export_stage_name="$2"
  local export_pytest_file="$3"
  local generate_stage_name="$4"
  local generate_pytest_cmd="$5"
  local model_age="$6"
  local tolerate_failure="$7"
  local batch_size="$8"
  local model_count
  local batch_count
  local batch_index

  if ! model_count="$(count_models_for_age "$model_key" "$model_age")"; then
    mark_failed "Count ${model_age} models for ${model_key}"
    return 0
  fi
  if ! [[ "$model_count" =~ ^[0-9]+$ ]]; then
    echo "Invalid model count for ${model_key} ${model_age}: ${model_count}"
    mark_failed "Count ${model_age} models for ${model_key}"
    return 0
  fi
  if [ "$model_count" -eq 0 ]; then
    echo "No ${model_age} models selected for ${model_key}; skipping."
    return 0
  fi

  batch_count="$(ceil_div "$model_count" "$batch_size")"
  echo "${model_key}: ${model_count} ${model_age} models, batch size ${batch_size}, ${batch_count} batches"

  for batch_index in $(seq 0 $((batch_count - 1))); do
    echo "Running ${model_key} ${model_age} batch $((batch_index + 1))/${batch_count}"
    run_export_stage \
      "${export_stage_name} (${model_age} batch $((batch_index + 1))/${batch_count})" \
      "$(_pytest_with_xdist "$export_pytest_file")" \
      "$model_age" \
      "$tolerate_failure" \
      "$batch_index" \
      "$batch_size"
    run_generate_stage \
      "${generate_stage_name} (${model_age} batch $((batch_index + 1))/${batch_count})" \
      "$generate_pytest_cmd" \
      "$model_age" \
      "$tolerate_failure" \
      "$batch_index" \
      "$batch_size"
  done
}
 
 
should_run() {
  local var="$1"
  if [ "${!var:-false}" != "true" ]; then
    echo "Skipping stage because $var=false"
    return 1
  fi
  return 0
}
 
############################################
# HTML email report
############################################
 
generate_email_report_on_host() {
  if [ -z "${NIGHTLY_DIR:-}" ]; then
    echo "NIGHTLY_DIR is not set; cannot generate host fallback report."
    return 0
  fi
 
  mkdir -p "${NIGHTLY_DIR}/${BUILD_NAME}"
  python3 tests/nightly_pipeline/nightly_email_report.py \
    --artifacts-dir "${NIGHTLY_DIR}/${BUILD_NAME}" \
    --output-html "${NIGHTLY_DIR}/${BUILD_NAME}/nightly_email_report.html" \
    --output-json "${NIGHTLY_DIR}/${BUILD_NAME}/nightly_email_report_summary.json" \
    --output-environment-json "${NIGHTLY_DIR}/${BUILD_NAME}/environment_versions.json" \
    --build-start-epoch "${BUILD_START_EPOCH}" \
    --build-end-epoch "${BUILD_END_EPOCH}" \
    --build-status "${BUILD_RESULT}" || echo "WARNING: Host fallback HTML report generation failed."
}
 
generate_email_report() {
  stage "Generate Email Report"
 
  BUILD_END_EPOCH="$(date +%s)"
  if [ "${FAILED}" -ne 0 ]; then
    BUILD_RESULT="failed"
  elif [ "${OLDER_MODEL_WARNINGS}" -ne 0 ]; then
    BUILD_RESULT="passed_with_warnings"
  else
    BUILD_RESULT="passed"
  fi
 
  if ! sudo docker ps -a --format '{{.Names}}' | grep -q "^${BUILD_NAME}\$"; then
    echo "Container ${BUILD_NAME} is not available; generating report on host."
    generate_email_report_on_host
    return 0
  fi
 
  _docker_exec "
    set -e
    export NIGHTLY_PIPELINE_ARTIFACTS_DIR=${NIGHTLY_ARTIFACTS_DIR}
    mkdir -p \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR\"
    cd /efficient-transformers
    if [ -f preflight_qeff/bin/activate ]; then
      source preflight_qeff/bin/activate
    fi
    python3 tests/nightly_pipeline/nightly_email_report.py \
      --artifacts-dir \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR\" \
      --output-html \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR/nightly_email_report.html\" \
      --output-json \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR/nightly_email_report_summary.json\" \
      --output-environment-json \"\$NIGHTLY_PIPELINE_ARTIFACTS_DIR/environment_versions.json\" \
      --build-start-epoch \"${BUILD_START_EPOCH}\" \
      --build-end-epoch \"${BUILD_END_EPOCH}\" \
      --build-status \"${BUILD_RESULT}\"
  " || generate_email_report_on_host
 
  echo "Nightly HTML report: ${NIGHTLY_DIR}/${BUILD_NAME}/nightly_email_report.html"
  echo "Nightly summary JSON: ${NIGHTLY_DIR}/${BUILD_NAME}/nightly_email_report_summary.json"
}
 
############################################
# ABORT HANDLER (CRITICAL FIX)
############################################
 
abort_handler() {
  echo "⚠️ Build aborted! Killing running processes..."
 
  for pid in "${CHILD_PIDS[@]:-}"; do
    kill -TERM "$pid" 2>/dev/null || true
  done
 
  kill -- -$$ 2>/dev/null || true
 
  echo "Stopping container immediately..."
  sudo docker stop -t 1 "${BUILD_NAME}" 2>/dev/null || true
 
  echo "Removing container..."
  sudo docker rm -f "${BUILD_NAME}" 2>/dev/null || true
 
  echo "Skipping workspace cleanup on abort"
 
  exit 1
}
 
############################################
# Normal cleanup
############################################
 
cleanup() {
  echo
  echo "=================================================="
  echo "CLEANUP: Docker + Workspace"
  echo "=================================================="
 
  sudo docker rm -f "${BUILD_NAME}" 2>/dev/null || true
  sudo chown -R ubuntu:ubuntu "${WORKSPACE}" || true
 
  echo "Cleaning workspace (preserving Nightly_Pipeline)..."
  find "${WORKSPACE}" -mindepth 1 -maxdepth 1 ! -name "Nightly_Pipeline" -exec rm -rf {} +
}

stage "Checkout Source"
 
cd "${WORKSPACE}" || exit 1
 
if ! git init; then mark_failed "git init"; exit 1; fi
git remote remove origin 2>/dev/null || true
export GIT_URL="https://github.com/quic/efficient-transformers.git"
if ! git remote add origin "$GIT_URL"; then mark_failed "git remote add"; exit 1; fi
if ! git fetch origin; then mark_failed "git fetch origin"; exit 1; fi
 
if [ -n "${PR_NUMBER:-}" ]; then
  echo "Checking out PR $PR_NUMBER"
  if ! git fetch origin "+refs/pull/${PR_NUMBER}/head:refs/remotes/origin/pr-${PR_NUMBER}"; then mark_failed "git fetch PR"; exit 1; fi
  if ! git checkout -B pr-${PR_NUMBER} FETCH_HEAD; then mark_failed "git checkout PR"; exit 1; fi
elif [ -n "${BRANCH_NAME:-}" ]; then
  echo "Checking out branch $BRANCH_NAME"
  if ! git fetch origin "$BRANCH_NAME"; then mark_failed "git fetch branch"; exit 1; fi
  if ! git checkout -B "$BRANCH_NAME" "origin/$BRANCH_NAME"; then mark_failed "git checkout branch"; exit 1; fi
else
  echo "Checking out main"
  if ! git checkout -B main origin/main; then mark_failed "git checkout main"; exit 1; fi
fi
 
export GIT_COMMIT="$(git rev-parse HEAD 2>/dev/null || true)"
git log -1 --oneline

  run_validate_stage "Validation" "pytest tests/nightly_pipeline/test_result_validation.py -v -s"
fi
 
 
############################################
# Final Status
############################################
 
stage "Final Status"
 
generate_email_report
 
stage "Sync Artifacts to WORKSPACE"
 
SRC="${NIGHTLY_DIR}/${BUILD_NAME}"
DEST="${WORKSPACE}/Nightly_Pipeline/${BUILD_TAG}"
 
echo "Source: $SRC"
echo "Destination: $DEST"
 
if [ -d "$SRC" ]; then
  mkdir -p "$DEST"
  cp -r "$SRC"/* "$DEST"/
  echo "✅ Artifacts synced to WORKSPACE"
 
  echo "=== DEBUG: Listing synced artifacts ==="
  ls -R "$DEST"
else
  echo "⚠️ No artifacts found to sync"
fi
 
find "$WORKSPACE/Nightly_Pipeline/${BUILD_TAG}" -name "*.lock" -delete
 
echo "FAILED = ${FAILED}"
echo "OLDER_MODEL_WARNINGS = ${OLDER_MODEL_WARNINGS}"
 
if [ "$FAILED" -ne 0 ]; then
  echo "One or more stages failed"
  exit 1
else
  echo "All stages succeeded"
fi
```
